# REQUISITOS

## Requisitos Funcionais

O sistema deve permitir:

- Adicionar uma tarefa;
- Introduzir título;
- Introduzir descrição;
- Listar todas as tarefas;
- Marcar/desmarcar favorita;
- Marcar como concluída;
- Editar tarefa;
- Eliminar tarefa;
- Guardar automaticamente no localStorage;
- Carregar automaticamente as tarefas ao abrir a aplicação.

## Requisitos Não Funcionais

- Interface simples e intuitiva.
- Código organizado em componentes React.
- Boa legibilidade.
- Responsiva (desktop e mobile).
- Boa experiência de utilização.
