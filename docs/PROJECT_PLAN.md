# Project Plan

## Informações Gerais

**Projeto:** To-Do List React

**Versão:** 1.0

**Estado:** Planeamento

**Metodologia:** Desenvolvimento Incremental por Sprints

---

# Visão Geral

A To-Do List React é uma aplicação web para gestão de tarefas desenvolvida com React.

O projeto foi criado como parte de um desafio académico, simulando um ambiente profissional de desenvolvimento de software.

Além da implementação funcional, o projeto prioriza boas práticas de arquitetura, documentação, organização do código e tomada de decisões técnicas.

---

# Objetivos do Projeto

## Objetivo Principal

Construir uma aplicação React organizada, documentada e pronta para publicação.

---

## Objetivos Técnicos

- Consolidar React.
- Aplicar JavaScript moderno.
- Compreender Hooks.
- Trabalhar com componentes.
- Utilizar Local Storage.
- Publicar na Vercel.

---

## Objetivos de Aprendizagem

Durante o desenvolvimento pretende-se compreender:

- JSX
- Componentes
- Props
- Estado
- Hooks
- Eventos
- Renderização
- Persistência
- Organização do projeto
- Deploy

Cada conceito será estudado antes da implementação.

# Escopo

## Fora do Escopo

- Base de dados.
- API.
- Sincronização online.
- Utilizadores.
- Categorias.
- Compartilhamento.

Estas funcionalidades poderão ser adicionadas em versões futuras.

# Metodologia de Trabalho

O projeto será desenvolvido em pequenas etapas.

Cada Sprint possuirá:

- Objetivo.
- Conceitos estudados.
- Desenvolvimento.
- Testes.
- Revisão.
- Documentação.

Nenhuma Sprint será iniciada sem que a anterior esteja concluída.

# Critérios de Sucesso

O projeto será considerado concluído quando:

- Todas as funcionalidades estiverem implementadas.
- O código estiver organizado.
- A documentação estiver completa.
- O projeto estiver publicado.
- O Developer conseguir justificar todas as decisões técnicas.

# Filosofia do Projeto

Antes de escrever código devemos compreender o problema.

Cada decisão técnica deverá possuir uma justificação.

O foco principal não é apenas desenvolver uma aplicação funcional, mas compreender profundamente os conceitos utilizados durante o desenvolvimento.
