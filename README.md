# To-Do List React

## 📖 Sobre o Projeto

A To-Do List React é uma aplicação web desenvolvida para gerir tarefas de forma simples, organizada e intuitiva.

Este projeto está a ser desenvolvido como parte de um desafio proposto pelo orientador/professor, simulando um ambiente real de desenvolvimento de software.

O objetivo não é apenas entregar uma aplicação funcional, mas também aplicar boas práticas de engenharia de software, planeamento, arquitetura, documentação e desenvolvimento com React.

---

# 🎯 Objetivos

Este projeto tem como objetivos:

- Consolidar conhecimentos em React.
- Aplicar JavaScript moderno dentro do ecossistema React.
- Desenvolver uma aplicação organizada em componentes.
- Implementar persistência de dados utilizando Local Storage.
- Publicar a aplicação na Vercel.
- Simular um fluxo de trabalho utilizado por equipas de desenvolvimento.

---

# 🚀 Funcionalidades

A aplicação permitirá:

- Adicionar tarefas
- Definir título
- Definir descrição
- Visualizar todas as tarefas
- Marcar tarefas como favoritas
- Guardar automaticamente os dados no Local Storage
- Restaurar automaticamente as tarefas ao abrir novamente a aplicação
